另一台电脑继续开发：
1. 仓库 https://github.com/bly9527/Powerbank-Test-Tool-V2.git ，分支 main。首次使用 git clone；已有副本先保存本地改动，再 git pull --ff-only origin main。
2. 在项目目录使用 Python 环境安装：python -m pip install -r requirements.txt；然后 python main.py 启动源码版。也可使用“启动测试工具.bat”，但它优先使用本机 Python 3.12，需确认依赖安装在同一个解释器中。
3. Git 只同步仓库文件，不会自动带走本机样本库、存档及原视频。要复现实验，请另外备份并迁移 %LOCALAPPDATA%\PowerbankTestTool 下的数据（合并前备份目标电脑原数据），也可通过软件导入导出模板包。原视频需另行复制；盘符改变后需重新选择视频，重新核对双机框选及模板勾选。
4. 本次 PB313 模板目录为 segment_samples\template_5ceada37d2f0469fb3cdadc3f7f4009d；使用采集框一号 [949,197,73,47]、二号 [1287,252,76,49]、旋转 0 度进行复测。这些是采集框，不保证与当前运行界面的框完全相同。
5. 后续优先在真实双机界面完成全流程验证（电量、时间、容量 OCR、记录回看和存档导出），检查高速模式下结果一致性，再决定是否打包。不要仅降低匹配阈值或按时间猜测缺失电量；保留基于视频证据的纠错保护。
